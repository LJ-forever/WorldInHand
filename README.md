# 真命 · MVP 原型

桌游式单机、PC、回合制探索游戏。Godot 4.7.2 + GDScript，内容数据驱动。

> **当前状态：v1.12 P0 可玩切片（即时战斗反馈、侦察先机、相邻即可突袭、距离制 AP、选择后揭示结果、固定地点、检查点仪式与分支共鸣、单槽自动存档、互斥任务与背包取舍、分策略平衡基线）**
>
> 已完成：
> - **v1.12 即时反馈、侦察先机与相邻袭击**：新增独立反馈层，命中时播放放射火花、冲击环、暴击斩线、伤害数字、连击提示、全屏微闪与地图震屏，并用运行时合成的音效覆盖命中、暴击、受击、未破防、侦察成功/大成功/失败与点击；所有 UI 按钮带按下缩小、松开回弹与点击音。侦察成功现在获得「侦察先机」（战斗 +2、幸运 +1，3 回合），大成功升级为「侦察洞察」（战斗 +3、幸运 +2，3 回合），重复成功会刷新，不侦察就会失去这段实打实的战斗与事件检定优势。袭击不再要求同伴先敌对：只要相邻且 AP 足够就能出手；对非敌对目标的首次袭击视为「突袭」，命中 +3 且目标来不及反击，无论命中与否都会强制转为敌对；对已敌对目标仍可能遭到反击。
> - **v1.11 检查点仪式与信息分层**：POI/地标悬停只显示名称、距离和状态，不再泄露商店价格、旅店费用或普通 POI 的发现奖励；进入商店会打开独立交易页，进入旅店会打开休息页，进入检查点则触发「封印石柱」仪式。仪式提供知誓 / 守誓 / 血契 / 离开四个选择：知誓揭示最近地点并 +8 金币，守誓恢复 2 HP，血契 −1 HP 并 +1 AP，离开不激活封印且可再次进入。三处仪式全部选择同一誓约时触发专属共鸣（知誓：+15 金币并指出终点方向；守誓：+2 HP；血契：+2 AP），混合选择只留下较弱的「残响」；最终共鸣写入结算页的本局回顾。
> - **v1.10 固定地点与地图悬停**：新增 `data/landmarks.json`，每张地图可通过 `landmark_counts` 在 POI 上放置 3 个「封印石柱」检查点、1 个「行商营地」商店和 1 个「路边旅店」。三类固定地点始终显示为小点标记（检查点青色菱形、商店金色方块、旅店蓝色圆点），离开视野只变暗；起点、终点、普通已知 POI、检查点、商店、旅店全部可用鼠标悬停查看名称、距离与状态（v1.11 起不再显示价格与恢复数值）。检查点决定终点封印，v1.11 起需完成仪式才激活；商店支持购买补给/药水/护符与出售兽皮/草药；旅店可花 8 金币恢复 3 HP、2 AP。没有 `landmark_counts` 的旧地图/旧存档自动回退到「任意 3 处 POI」封印；地标分配使用独立种子，读档重建位置不变。固定种子 50 局复跑与 v1.9 一致：赶路 76% / 15.7 回合、谨慎 80% / 21.0 回合、激进 18% / 11.6 回合；三种策略的封印拦截均为 0，说明检查点已先于终点完成
> - **v1.9 复审修正**：终点改为先踏足 3 处地点解除封印，封印未解时移动停在终点格外，并把标记吸回当前格；守卫「退开」每回合只压制本回合、每局最多成功 2 次，交出物品改为消耗物品 + 交涉检定 DC 13（稀有度 +1/+2/+3），不再直接通过；连续两次检定失败后 DC −2；青蘅交涉 3 → 4；影首次偷窃前先给一轮预警，失窃提示指向背包页，击败影直接取回失物，结算页显示失物与致命事件名；赶路/谨慎/激进三种 bot 各 50 局复跑显示赶路 76% / 15.7 回合、谨慎 80% / 21.0 回合、激进 18% / 11.6 回合；平衡报告把终点守卫从事件池份额改为「守卫尝试/局」，中立追击按同伴拆分核对
> - **v1.8 复审修正**：单段移动成本封顶 3 AP，修复 AI 在陡坡/长边因格心近似算出超过整回合 AP 而长期不动；阵营阈值回到设计 §11.3 的 `≥ +3` 友方 / `≤ −3` 敌方，互斥目标完成按 §11.4 强制转敌；影的偷窃任务改为初始中立并加任务完成前失败好感下限（A24），使首次失窃后的 D-25 追回真正可达；终点守卫新增无检定「退开」；事件切换/背包页/结算时清理旧骰子与底栏；`grant_item()` 拒绝未知物品 ID
> - 数据层（8 张内容 JSON 表 + 地图配置）与启动自检
> - 开局流程：主界面 → 选择地图文件 → 选择角色 → **开场白 → 进入地图**
> - **事件结算的收获/线索/代价摘要**：选择前仍只显示选项与风险；检定或交易完成后，结算页先用「◆ 收获 / ◇ 线索 / ◆ 代价」把实际得到的物品、金币、状态、好感与地图情报分类列出，再给可操作提示（如「可在背包（B）中装备/使用」）。同一句结果不会在下方重复出现
> - **可用的消耗品**：背包里的补给可直接选择恢复 1 HP 或 1 AP，药水可解除一个 `removable_by_potion` 负面状态；选择前会显示当前 HP/AP 与可解除状态，满值或没有目标时按钮禁用并说明原因，失败使用不会消耗物品
> - **POI 首次探索回报**：每处 POI 第一次踏足必定给一份保底发现奖励（补给 / 5～9 金币 / 药水），同时照常必定触发地点事件；HUD 回合信息显示「探索 N/M」，首次踏足地点与奖励会进入旅途纪事和顶部提示。保底奖励走独立 `exploration` 随机流，不改变事件与检定序列；同一次存档不会重复领取
> - **同伴羁绊与里程碑**：同伴状态栏始终显示定性羁绊（敌意/冷淡/谨慎/亲近/信赖），不再只有情报 3 级才能看到关系；好感首次达到 +4 时触发一次性「信赖」里程碑，同伴会赠送 1 份补给并写入纪事/提示，之后不会重复触发
> - **结局本局总结**：胜利或失败结算页在原因下方追加「本局回顾」：回合数、探索地点数、遭遇事件数、金币/行囊/装备、同伴关系与剩余距离或胜利层级，让玩家能回看这一局积累了什么
> - **开场白与可直接读出的关系**：选完角色后先展示一页序章，用第二人称交代玩家身份、同伴身份、为何同行、为何在岔路口走散（同伴从 3～6 格外另一条路出发）、40 回合目标与终点规则；底部直接写明「关系：互相照应（友好）/ 同路试探（中立）/ 旧怨未清（敌对）」及该关系对玩法的含义，按「踏入荒原」后才解锁操作
> - JSON 地图配置：1 张内置随机地图 + 本地 JSON 载入
> - **地图即内容清单**：每个地图 JSON 用 `character_ids` / `event_ids` / `landmark_counts` 声明本图可用的角色、事件与固定地点；角色选择、AI 对手、事件池和地标分配都只读取该清单。当前唯一内置图列全 5 名角色、18 个事件、3 个检查点、1 个商店与 1 个旅店，单图即可回归全部内容；后续新增西幻、玄幻等风格地图时可各自绑定不同清单
> - **隐藏任务**：任务表按 AI 同伴视角撰写，不能当作玩家目标。按设计文档 §10.5，玩家侧只记录所选角色的 2 个 MVP 候选，不分配、不判定，暂停菜单与手册明确标注「玩家隐藏任务：MVP 未启用」；AI 同伴独立抽 1 个任务并保持隐藏
> - **AI 同伴完整行动**：每回合独立掷 AP，处理持续伤害/状态、低血量自动用药、被困挣脱，再按隐藏任务与阵营选择目标——向玩家靠拢支援、跟踪偷窃/下套、探索 POI 并拾取物资、独立侦察、休整，或直奔终点尝试通过守卫。单回合最多跨 6 格，不再只有玩家一半的移动节奏；支援任务在距离玩家超过 3 格或玩家有紧急伤情时优先靠近，进入 3 格内才侦察、搜集或望风。回合结束在底栏报出当前动向与一句符合阵营/处境的台词，但只有看见她或她在 3 格听觉范围内时才听得到
> - **任务驱动的阵营与关系**：`hidden_tasks.json` 的 `initial_faction` / `initial_favor` 决定初始立场，任务完成条件决定行动倾向；按设计 §11.3，好感 `≤ −3` 转敌方、`≥ +3` 转友方，−2～+2 为中立；互斥目标完成时按 §11.4 直接转敌，即使高好感扣到 −2 也不会停留在中立。事件中的 `ai_favor` 与 AI 援助/偷窃会改变好感，跨越阈值时世界纪事和事件结算都会给出反馈；敌方同伴在情报足够时显示警告标记
> - **主动战斗与反击**：敌方同伴在相邻时会消耗 1 AP 主动袭击；玩家只要与同伴相邻且 AP 足够，就能点「袭击（1 AP）」，不再要求她先敌对。若她尚未敌对，这次是「突袭」：命中 +3、她这一下无法反击，且出手后关系立刻转为「敌对」；若她已敌对，则按旧规则在她存活且 AP ≥1 时可能反击一次。按钮会显示当前状态（可突袭 +3 / 可发动 / 不可用原因），悬停说明用途与结算方式。双方共用 `CombatRules`：2d6 + 战斗 + 装备 + 状态 + 情境加值 对抗 `8 + 体力 + 装备防御加值`；成功 1d3 伤害、大成功 1d6，失败额外 −1 AP（不足转 HP），大失败攻击者 −1 HP。战斗面板显示两枚骰子与结算文本，玩家可再花 1 AP 反击；自动流程（测试）默认承受攻击，避免等待输入
> - **终点封印、先到奖励与胜利分层**：进入终点前必须先激活地图上的全部检查点（内置图 3 个青色「封印石柱」；没有检查点的旧地图退回踏足 3 处地点。`random_events_enabled = false` 的调试/测试模式不启用封印）；封印未解时角色停在终点格外，画线标记会吸回当前格，HUD 回合信息显示「终点封印 N/3」。第一个通过终点守卫的角色获得 +20 金币，同回合抵达者并列获奖；AI 未通过守卫不计到达。玩家抵达时，若任一敌方同伴已经站在终点（按到达瞬间阵营快照判定），结算为「基础胜利」；否则为「完美胜利」。同回合的同伴仍获得一次仅冲向终点的最后行动，用来判定并列
> - **情报分级与四级同伴标记**：玩家对同伴的认知从 0（完全未知）到 3（友好度与目标）；未见面时只显示倾向/阵营线索。地图标记分四种：视野内实心彩点（跟随真实位置）、视野外但 3 格内「听声辨位」的虚化圆环与声波（同样跟随真实位置）、4 回合内的空心「最后已知」标记（固定在最后感知到的格子）、未知时不绘制；情报不足时不透露精确位置
> - **旅途纪事与同伴面板**：HUD 顶栏显示同伴名字与关系，底栏动作按钮下方固定显示「同伴 · 当前动向 · 距你 N 格」和一句台词；暂停菜单汇总情报等级、好感、当前状态、最后已知方向、任务线索与最近世界纪事；AI 的可见行动、传闻、任务完成、阵营变化和玩家事件都会写入纪事。**纪事标题栏可点「收起/展开」，面板内保留完整记录并支持鼠标滚轮浏览**；折叠后只留标题行，不再遮挡地图
> - **持续状态条**：左上角常驻显示当前诅咒/祝福/持续伤害的短效果（红=负面，绿=祝福），例如「被诅咒（幸运 -2，药水无效）」「隐士祝福（感知 +1，侦察更远）」；悬停可看完整说明、剩余回合与药水能否解除。事件关闭后仍能看到自己中了什么，不会随弹窗一起消失
> - **右侧「？」旅途手册**：顶部右上角问号按钮打开六页帮助（操作、移动与 AP、侦察与迷雾、袭击与战斗、背包与装备、同伴与目标），底栏不再堆放会溢出屏幕的长提示；开手册时暂停游戏，关闭后恢复
> - **背包与装备页（A3/D-25）**：底栏「背包（B）」打开独立页面，左侧装备栏、右侧背包；悬停物品看类型、稀有度、效果、描述与操作说明，可装备物品从右侧拖到左侧槽位，也可点击直接装备/卸下；补给与药水点击后出现「使用」操作，可直接恢复 HP/AP 或解除负面状态；装备立即影响 AP、战斗、侦察、交涉或移动消耗。玩家背包按物品**种类**计 8 格（同种叠加只占 1 格）；满格时获得的物品先排队，HUD 会在安全边界自动打开背包页，让你**丢弃 1 件收下新物品**或**放弃新物品**，放弃后它永久丢失，未完成取舍前不能关闭背包页。被影偷走物品后，背包页会出现「追查失物（免费）」：每回合可做一次感知检定 DC 12，不耗 AP；成功归还物品、影好感 −3，但不会撤销她已完成的任务
> - **敌方互斥目标与即时胜负（A6/D-31/D-32，v1.8 起按 A24）**：影的偷窃任务初始为中立、好感 0～1；任务完成前偷窃失败最多扣到 −2，不会提前转敌。首次动手前会先给玩家一轮预警；首次得手时若她当时为敌方，本局**立即失败**；若为友方/中立，则好感 −5 强制转敌，不立即判负，物品转入她的 3 格背包，可通过上面的免费检定追回；击败影会直接取回失物。之后若她因其他原因再次回到敌方，再得手才立即判负。失败结算页会显示致命事件名与失物，不再只有「你在事件中倒下」。薇拉成功施困不会当场判负，而是在你抵达终点时仍 `trapped`，或终局/超时未到达时完成目标；敌方完成同样立即失败。青蘅分享、林鸮测绘、沙铠携带只改变她们的任务/好感/阵营，不直接改写你的结局。AI 背包满时优先丢非任务材料，其次非任务消耗品，任务物品永不自动丢弃
> - **骰子动画与公式来源**：开局 AP、每回合 AP、侦察、事件检定、陷阱挣脱、战斗攻击与反击都会在顶部显示骰面滚动、修正、合计、DC 与结果等级；结算文本把每一项加值写成「数值（来源）」，例如 `2d6（7） + 4（感知） + 1（望远镜） - 1（中毒）`、`1d6（3） + 4（速度） + 1（坐骑） = 8 AP`、`DC 12（10（基础） + 2（密林））`，不再只显示一个无法追溯的总值。动画不阻塞结算，也不会拦截地图输入
> - **分层迷雾**：地形底色始终先完整绘制；未知黑层与「曾获得信息」的压暗层是独立覆盖层，同一地块可以同时拥有基础地形色、黑色未知雾或低亮度记忆雾。圆弧仍会切过边缘地块，不会整格吸附
> - Voronoi 不规则地块地图：约 150～800 个候选格、单图实际约 279 块；地块面积有大有小且无极端碎块/巨块、凸凹地块混合、3 地形、高程、10 个 POI、内陆起点/终点、生成校验、地块形状同种子可复现
> - **每局随机地图**：内置图 `randomize_seed = true`，每次开始新游戏都会重掷形状种子；地块轮廓、数量、POI、起终点、海拔与生态分布都会变化。HUD 显示本局实际种子，`同种子重开` 会保留当前地图
> - 回合开始掷 AP（1d6 + 速度 + 装备，上限 12），显示 1 位小数
> - 从角色处按住左键自由画线，路线跟随手绘轨迹，可任意弯曲
> - 地图缩放与平移：滚轮以光标为中心缩放、中键拖动画布、`Home` 复位；默认视图在顶部信息条与底部动作栏之间居中整张地图
> - 画线时不显示 AP 消耗、可达性与截断点，只显示线本身
> - 移动动画：角色沿手绘轨迹前进，**AP 按实际走过的路径距离连续消耗**，不再按地块一次性收费；同一个地块内可以反复移动、反复画线，直到 AP 耗尽。进入新地块的成本取决于你从当前格的哪个位置出发——靠近边界比远离边界更省 AP。只有进入新地块时才检测到达事件；AP 耗尽时角色停在路径上的实际位置，不会在最后突然闪现回地块中心
> - **18 个事件接入**：商队、野火、马匪伏击、草药丛、沙尘暴、古井、迷路、废弃营地、流浪者、悬崖、神秘石碑、倒木当道、沙海蜃景、朝圣者、终点守卫、封印石柱检查点仪式，以及固定地点设施「行商营地」（购买/出售）与「路边旅店」（花金币休息）

## 快速开始

1. 双击桌面 `Godot 4.7.2` 快捷方式
2. 项目管理器 → `Import` → 选择 `E:\GodotProject\project.godot` → `Import & Edit`
3. 按 **F5** 运行
4. 主界面点「开始」→ 选择地图文件 → 选择角色 → 阅读开场白 → 点「踏入荒原」进入地图
5. 中途返回主界面或退出后，主界面会出现「继续游戏 · 第 N 回合」；点击即按存档重建地图、角色、同伴、事件与迷雾，从该回合继续

内置地图只保留 `data/maps/borderland.json`。它用 `randomize_seed` 标记为每局随机：每次从角色选择进入游戏时，`GameManager` 都会重掷形状种子，因此地块轮廓、POI、起终点、海拔与生态分布都会变化。地图 JSON 还可以用 `character_ids` 与 `event_ids` 声明本图内容清单，并用 `landmark_counts` 指定检查点/商店/旅店数量；角色选择界面只显示清单内角色，游戏内事件池也只从清单内抽取，地标只分配到本图 POI 上。省略这些字段时回退到全量内容且不生成固定地标，兼容旧地图与本地临时配置。新增固定地图或不同风格地图时，复制一份 JSON、调整参数与清单，重开游戏即可出现在地图选择界面；也可以在地图选择界面点「打开本地 JSON…」直接载入任意外部配置。

| 按住左键从角色处拖动 | 自由画出行进路线（轨迹可任意弯曲） |
| 松开左键 | 固定路线；由轨迹生成连续地块序列 |
| 右键 | 清除当前路线 |
| 空格 / 回车 /「沿路径移动」 | 角色沿路线播放移动动画，按实际距离连续扣除 AP |
| 「休息」 | 每回合一次，回复 1 HP，不耗 AP |
| 「侦察（2 AP）」 | 2d6 + 感知 + 装备/状态 对抗当前地块的侦察 DC；成功扩大圆形视野并获「侦察先机」（战斗 +2、幸运 +1，3 回合）；大成功额外定位最近 POI 并升级为「侦察洞察」（战斗 +3、幸运 +2，3 回合）；大失败暴露位置 |
| 「袭击（1 AP）」 | 与同伴相邻且 AP 足够即可袭击；非敌对目标会吃「突袭 +3」且当次无法反击，攻击后强制转敌；已敌对目标存活且 AP ≥1 时可能反击。结算带命中特效、伤害数字、连击提示、震屏与合成音效 |
| 战斗面板 | 敌方袭击时选择「消耗 1 AP 反击」或「承受这一击」；结算后点「继续」恢复行动 |
| 右上角「？」 | 打开六页旅途手册（操作、AP、侦察与迷雾、袭击与战斗、背包与装备、同伴与目标）；打开时暂停，`Esc` 或「关闭」返回 |
| 「背包（B）」 | 打开装备/背包页：左侧装备、右侧背包；悬停看详情，可装备物品可拖到左侧槽位，也可点击装备/卸下；点击补给/药水后可直接使用。背包满时在此丢弃物品或放弃新物品；失物存在时可点「追查失物（免费）」 |
| 「结束回合」 | 回合数 +1，重掷下回合 AP |
| 「清除路径」 | 清除当前路线 |
| 事件面板选项 | 选择一个检定/交易/偷窃/献祭/恢复/誓约选项；选择前只显示选项与风险，结算后才列出实际获得的物品、状态与代价，点「继续」关闭事件。商店的「看看货物」会进入独立交易页，旅店的住店选项进入休息页，检查点进入封印仪式页 |
| 左上状态条 | 常驻显示诅咒/祝福/持续伤害的短效果；悬停查看完整数值、持续回合与药水能否解除 |
| 旅途纪事「收起/展开」 | 折叠后只保留标题行；展开时用滚轮浏览完整纪事，新增记录会自动滚到底部 |

画线阶段**不显示**路径 AP 成本、能否到达、会在哪里停下。AP 在移动动画中按实际路径距离连续扣除，进入新地块时扣除的是「从当前位置走到该格边界」的那一段成本；同一个地块内反复移动也会持续消耗 AP，直到耗尽。AP 不够走完当前线段时，角色停在路径上的实际位置（不会跳回当前格中心），并提示「AP 不足，停在路径上的实际位置」以及剩余 AP。路径可以完全在当前地块内；角色停在格边时，从标记附近起笔仍会按当前位置继续画线，不会因为边界判定被拒绝。事件只在进入新地块时触发。

一次移动行动中最多结算 **2 个事件**，两次事件开始之间至少消耗 3 AP；同一触发源（POI / 新区域 / wander）在一次行动中最多触发 1 次，每回合最多 3 个随机事件。事件界面关闭后自动继续沿剩余路径移动，因此大地图上一次画线可能连续遇到多个不同事件。

一个回合内可以**多次行动**：AP 是唯一预算，只要还剩 AP，就可以反复画线移动（后续物品/技能同样按 AP 消耗），不需要「每回合只能行动一次」。休息不耗 AP，但每回合最多 1 次；「结束回合」用于主动放弃剩余 AP、进入下一回合。

界面固定分为三块：顶部信息条显示回合、AP、HP、金币、地形与坐标，右上角「？」打开旅途手册；底部动作栏放「沿路径移动」「侦察」「袭击」「休息」「背包」「结束回合」等按钮，按钮下方固定一条同伴状态与台词；画面左上角的悬停条在地块上显示地形/海拔，移到地图小点上则只显示起点、终点、普通 POI、检查点、商店或旅店的名称、距离与状态（检查点显示序号与是否激活，终点显示封印进度）；商店价格、旅店费用与仪式分支不在悬停条出现，进入对应子页面后才展示。悬停信息不再占用右下角。所有长提示都移进手册，底栏不会再被文本撑出屏幕。移动被状态阻挡时，底部提示条会直接说明是「被困」「迷路」还是 AP 不足，并给出对应处理方式。角色与同伴的地图圆点已缩小；两者同格时按固定偏移并排画在同一地块内，不再把其中一个推出格外。

地图上的标记：绿色圆环 = 起点，金色圆环 = 终点（二者始终可见，悬停看终点封印进度）；金色小圆点 = 已进入、已侦察或被事件揭示的普通 POI，悬停只显示地形、距离与探索状态；青色菱形 = 检查点「封印石柱」，金色方块 = 商店「行商营地」，蓝色圆点 = 旅店「路边旅店」，三类固定地点始终可见，悬停只显示名称、距离与是否激活，进入后分别打开封印仪式、交易页与休息页，离开视野后只降低亮度；金色圆点 = 玩家；实心彩色圆点 = 视野内的同伴（绿色友好 / 灰色中立 / 红色敌对，情报 ≥2 才显示阵营色）；虚化圆环 + 两道声波 = 视野外但 3 格内、只能听声辨位的同伴，标记跟随她的真实位置；空心环 = 同伴最后已知位置（固定在最后感知到的格子，保留 4 回合，情报不足时不显示具体方位）；灰色叉号 = 同伴已经倒下；敌方同伴在情报 ≥2 时，标记上方会出现警告短线。超过 3 格且没有有效记忆时不绘制同伴标记。

## 实现备注

- **地图**：Voronoi 不规则地块铺满一块凸的不规则海岸线，不是六边形蜂窝。格数、边界粗糙度、地形权重、梯度、高程、POI 数量都由 `data/maps/*.json` 控制；地块形状在同配置 + 同形状种子下完全复现，生态分布则每局重掷（见下一条）。详见决策记录 D-05/D-06。
- **凹地块**：生成完 Voronoi 凸块后，随机把相邻的 2～3 个块用 `Geometry2D.merge_polygons` 合并；只接受单轮廓、真正带凹角、且合并后面积不超过平均 2.30 倍的结果。合并块照常参与邻接与路径，`cell.concave` 标记其形状。地块名称与悬停/点选都按合并后多边形判定，而不是按站点最近距离。详见 D-46。
- **每局随机地图与生态重掷**：地图 JSON 标记 `randomize_seed = true` 时，`GameManager.start_new_game` 每次开局重掷形状种子；`MapGenerator` 用它重建地块轮廓、POI、起终点与高程。生态种子仍单独随机生成，由 `MapGenerator` 从地图中心开始 BFS 生长地形。每格权重 = 基础权重 + 方向梯度 + 已定型邻格影响：同类相邻会聚成片，沙漠旁的森林被压成平原过渡带。因此每次进入游戏，地图内容与群系分布都会变化；HUD 显示本局实际形状种子，`同种子重开` 会关闭重掷并保留当前地图。详见 D-47/D-53。
- **地块大小**：站点不再等距铺满，而是先以 0.74×平均间距生成候选点，再由低频 `FastNoiseLite` 密度噪声决定保留概率（25%～80%），形成大小地块混合；随后做两轮细化，低于平均面积 0.46 倍的小格移除、高于 2.40 倍的巨格拆分。最终面积允许约 0.22×～2.80× 平均面积，超出该范围的异常格不超过 4%。`cell.area` 只用于地图形态与渲染，不再折算单格 AP。
- **缩放与平移**：`MapView` 用 `draw_set_transform(平移, 0, 缩放)` 统一缩放整张地图；所有鼠标输入先由 `_screen_to_world` 转成地图坐标，再用于画线、悬停和海拔查询。滚轮缩放以光标为锚点，中键拖动平移；默认视图会把整张地图放进顶部信息条与底部动作栏之间的可读区域，`Home` 重新计算这个适配视图，不再为旧信息框预留右侧空间。地图坐标不变，因此画好的路径在缩放/平移后仍贴合原处。详见 D-45/D-48。
- **格内非均匀高程**：规则结算仍以整格 `elevation` 为代表值，但每格额外保存 `elevation_samples`（多边形顶点与边中点各一个高程采样）、`elevation_mean` 和 `relief_min/max`。悬停时 `elevation_at(cell_id, point)` 对格内采样点做反距离加权，HUD 显示光标处的实际海拔与该格范围，例如「海拔 2.8（格内 1.7–3.3）」。渲染继续按多边形边界绘制，格内高度和顶点色在相邻地块间混合；移动成本用 `elevation_at` 采样实际起止点的海拔来计算爬升，因此同一地块内不同位置的移动也会有真实高差成本。
- **圆形迷雾与侦察**：视野是以角色为圆心、以世界像素计算半径的圆。每格仍只保存 `seen` / `scouted` / `entered` 三个持久标记。渲染是**分层**的：先无条件绘制完整地形底色与起伏，再在地形上叠加雾层——`VISIBLE` 不叠雾，`REMEMBERED`（有历史信息但当前在圆外）叠低亮度记忆雾，`UNKNOWN` 叠近黑未知雾（仍留少量底色透出，让玩家能看出这里是地形而不是空洞）。因此同一地块可以同时拥有基础地形色与雾层，不会出现“雾把地形颜色替换掉”的效果。渲染时把每个地块减去视野圆，只给圆外部分上雾，因此**圆弧会切过边缘地块**，不会整格点亮。被动视野半径 = 平均格径 × 2；每进入新格重建。侦察成功把圆形视野额外扩大 `感知 ÷ 2 + 1` 格（以平均 POI 间距折算世界半径），保持 2 回合后每回合收缩 0.5 格，直到回到基础圆；同时施加 `scout_edge`（战斗 +2、幸运 +1，3 回合），大成功改为 `scout_insight`（战斗 +3、幸运 +2，3 回合）并额外 +1 格、揭示最近未探索 POI；重复成功刷新持续时间，大成功移除并取代先机。AI 揭示等级 +1（上限 3），大失败使位置暴露到下一回合结束。悬停按光标点是否在圆内判断，普通 POI 标记只在已知且可见/记忆状态绘制；检查点、商店、旅店与起终点不受此限制。详见 D-54（修订）、D-69、D-72。
- **暂停与退出**：进入地图后只能通过 `Esc` /「菜单」打开暂停层，不再提供游戏内地图切换。暂停层展示同伴情报等级、好感、当前状态、最后已知方向、任务线索与最近世界纪事，不再放装备/背包（已移到独立背包页）。暂停用 `get_tree().paused`，HUD 与暂停层设为 `PROCESS_MODE_ALWAYS`；「返回主界面」与「退出游戏」都会先调用 `GameManager.autosave()`，再回到 `main_menu.tscn` 或关闭进程。详见 D-43A/D-48/D-63。
- **开场白**：角色选择确认后不直接解锁地图，而是由 `GameManager.start_new_game()` 生成 `intro_story` 并置 `intro_open`；`IntroOverlay` 显示玩家身份、同伴身份、同行理由、为何走散、关系标签与 40 回合目标。点「踏入荒原」调用 `dismiss_intro()`，先发 `intro_dismissed` 再发开局 AP 骰子。所有移动/侦察/袭击在 `intro_open` 期间都会被拒绝并给出提示，自动测试通过辅助函数直接关闭序章。详见 D-60。
- **HUD 布局与旅途手册**：顶栏只保留回合/AP/HP/金币/地形/种子与右上角「？」，底栏动作按钮按两行排列，同伴条固定在按钮下方；长提示全部移入 `HelpOverlay` 的六页分页。左上悬停条下方新增常驻状态条，左下纪事标题栏带「收起/展开」并把正文放进 `ScrollContainer`；状态条与纪事都接收鼠标，悬停/滚轮不再穿透到地图。帮助/背包打开时暂停场景，关闭后恢复；两者都有 `closed` 信号供 HUD 恢复焦点。布局测试会检查底栏和「？」按钮都留在 1280×720 视口内。详见 D-48/D-60/D-61。
- **背包与装备页**：`BackpackOverlay` 左列是 `ItemSlot` 装备槽，右列是背包网格；悬停显示类型、稀有度、效果、描述与当前操作，可装备物品通过 Godot 原生拖拽从背包放到槽位，也支持点击装备/卸下。装备改动立即刷新 `ActorState` 的 AP、战斗、侦察、交涉与移动消耗。玩家背包 8 格按物品种类计数；`GameManager.grant_item()` 是 POI、交易、事件、偷窃与里程碑奖励的统一入口，未知物品 ID 会被拒绝并提示，满格时进入 `pending_item_overflows`，由 HUD 在安全边界打开背包页完成「丢弃换入」或「放弃」。失物存在时背包页顶部显示「追查失物（免费）」，调用 `GameManager.recover_stolen_item()` 完成 D-25 检定；溢出队列、失物 ID 与追查回合都随存档恢复。详见 A3/D-25/D-66/D-67。
- **骰子动画**：`GameManager.dice_rolled` 与 `EventManager.dice_rolled` 统一驱动 `DiceOverlay`；`DiceFace` 先快速滚动 8 个随机面，再落定到真实点数，摘要显示骰式、修正、合计、DC 与结果等级，停留后淡出。覆盖开局 AP、每回合 AP、侦察、事件检定、陷阱挣脱与战斗攻击/反击。覆盖层 `MOUSE_FILTER_IGNORE`，不改变任何结算顺序。详见 D-60。
- **即时战斗反馈层**：`GameManager.combat_hit` 把每次已结算攻击的攻击方、目标、伤害、等级、暴击与连击数发给独立的 `FeedbackLayer`（位于 `UI` 最后一个子节点，`MOUSE_FILTER_IGNORE`）。命中时在受击者屏幕位置生成放射火花、冲击环、暴击斩线与浮动伤害数字，连击 ≥2 显示「连击 ×N」，受击侧还触发全屏微闪和 `MapView` 震屏；侦察成功/大成功/失败也接入 `scout_finished`，播放对应的先机/洞察提示。音效不依赖外部资源，由 `AudioStreamWAV` 在运行时合成并缓存；所有 UI 按钮（包括运行时生成的事件选项）按下缩小、松开回弹并播放点击音。该层不读写规则状态，震屏只临时改 `MapView.position` 并在结束后复位。详见 D-71。
- **开局流程**：主界面只负责进入游戏；地图文件在第二步选择（内置/本地 JSON）；角色在第三步选择。唯一内置图标记为每局随机，点角色进入时才真正掷出本局地图。详见 A8/A16。
- **地图内容清单**：`data/maps/*.json` 里的 `character_ids` / `event_ids` 决定本图可选角色与事件池；`GameManager.available_character_ids()` / `available_event_ids()` 是统一入口，角色选择、AI 抽取、事件加权都经过它。字段省略时回退全量，写了则必须非空、无重复、引用存在。当前唯一内置图列全量内容，方便单图回归全部效果。详见 D-52/A15。
- **隐藏任务**：`hidden_tasks.json` 的条目是 AI 同伴视角（例如「与玩家友好度达到 +3」），不能直接当成玩家目标。按设计文档 §10.5，玩家角色在 MVP 只记录自己的 `mvp_available` 候选（`GameManager.player_hidden_task_candidate_ids`），不分配、不判定、不参与胜负；暂停菜单与旅途手册明确标注「玩家隐藏任务：MVP 未启用」。AI 同伴则用 `hidden_task_ai` 随机流从自己的候选中抽 1 个，存于 `GameManager.ai_hidden_task_id`，对玩家保密，由 `CompanionAI` 用作阵营、好感与行动倾向。详见 D-55/D-56/A18。
- **AI 同伴回合**：每回合结束时 `GameManager._run_companion_turn()` 让 `CompanionAI.take_turn()` 独立行动：掷 AP → 结算持续伤害/状态 → 低血用药 → 挣脱陷阱 → 按 `completion.type` 与阵营选意图。友方任务走援助，敌方任务走跟踪/偷窃/下套，中立与竞争者走侦察或终点；探索会进入 POI 拾取物资。**支援会主动靠近**：距离玩家 >3 格或玩家有紧急伤情时，先沿最短路径靠拢；进入 3 格内才转为独立侦察、探索拾取或望风。单回合最多跨 6 格，AI 寻路使用格心到格心的近似距离，逐格按地形与海拔扣费（与玩家沿完整画线的精确成本区分），单段成本同样受 3 AP 上限保护。AI 与玩家同格/相邻才发生真实互动（分享、包扎、偷窃、下套），探索可直接踏入；随机全部走 `"ai"` 流。每次行动结束生成一句按意图、阵营、玩家处境选择的台词，但只有视野内或 3 格听觉范围内才显示；更远只保留最后已知位置。详见 A19/A21/D-56/D-60/D-67。
- **袭击可用性与目的**：`GameManager.attack_block_reason()` 是唯一判定入口，按钮禁用状态、悬停说明与点击反馈都读它。现在只检查开场白/行动阶段/移动/目标存活/AP/相邻，不再检查阵营；按钮会写「可突袭 +3」「可发动」或具体不可用原因。对非敌对目标的首次袭击由 `attack_is_surprise()` 判定，`CombatRules.resolve_attack(..., 3, "突袭")` 把 +3 单独记账并写进公式；`force_hostile()` 在结算时强制转为敌对，且该次不触发目标反击。对已敌对目标仍按旧规则在她存活且 AP ≥1 时反击。手册「袭击与战斗」页同步解释突袭加值、无反击与关系代价。详见 D-60、D-72。
- **地图尺度与起终点**：内置图单局约 279 块，起点与终点都从距边界至少若干格的内陆候选点中选取，不再固定贴边；同伴从玩家 3～6 格外的另一条路出发，序章会说明走散原因。生成后会用图距离、每回合平均 AP 与事件预算校验 40 回合内可完成。详见 D-47/D-60。
- **阵营、好感与情报**：好感范围 −5～+5，按设计 §11.3，`favor <= -3` 敌方、`favor >= 3` 友方，−2～+2 为中立；互斥目标完成按 §11.4 强制转敌。初始值来自任务 `initial_faction` 与 `initial_favor` 区间；影的偷窃任务按 A24 初始中立（0～1），任务完成前失败最多扣到 −2。玩家对同伴的情报等级 0～3 由侦察/事件提供，0 级只给模糊反应，1 级显示好感变化，2 级显示阵营色/警告标记，3 级才显示任务名与进度。视野外的同伴继续行动，玩家只看到 4 回合内的最后已知位置、方向提示、传闻和可见行动文本。
- **旅途纪事**：`GameManager.world_log` 统一记录开局、玩家事件、AI 可见行动、传闻、任务完成、阵营变化、死亡与终点竞争，最多 30 条；HUD、暂停菜单与事件结算都读同一份纪事，避免“画面里发生了但玩家不知道”。详见 D-56。
- **事件编排**：`EventManager._context_weight()` 在基础权重、地形、冷却和防重复之后，再按 HP 比例、通缉、剩余回合与同伴阵营/距离做软加权（0.2～2.0，不硬锁事件）；`get_context_note()` 解释当前压力。选项的 `risk` 由 DC 与失败后果计算；选择前不下发 `preview` / `hint` / `warning`，事件面板只渲染选项按钮与风险文案。检定完成后，`_resolve_outcome()` 实际施加效果，并把获得的物品名、状态数值、同伴影响与位置变化写入 `effect_messages`，结算页直接展示这些真实结果。详见 D-57/D-62。
- **事件中的同伴**：结果里的 `ai_effects` 只在同伴与玩家同格/相邻时结算，且只有本人可见时才显示具体伤势/物品变化；`ai_favor` 不受距离限制，直接改变关系与阵营。AI 物品选择会读取 `choose_from` 与 `ai_task_aware`，优先拿自己任务需要的可交易物。
- **自由画线**：鼠标拖出的原始折线用于显示，并在 `GameManager.set_drawn_path` 中加密采样、按顺序映射为连续地块；跨格跳变用最短路补齐，移动时角色沿原手绘轨迹插值，不是逐格中心跳格。路径可以完全位于当前地块内。详见 A9/D-09/D-62。
- **隐藏路径信息**：画线阶段 HUD 不显示路径成本、截断点或可达性；AP 在移动动画中按实际路径距离连续扣除。终点距离仍显示（这是地图信息，不是路径信息）。详见 A9/D-62。
- **移动与事件**：`advance_movement(delta)` 按 260 px/s 推进；每帧把目标距离映射到预先按 `segment_move_cost_deci` 累加的成本曲线上，连续扣除 AP，因此格内移动也会扣费。进入新格时更新 `player.cell_id`、发 `cell_entered` 并调用 `EventManager.on_cell_entered`。命中事件时移动暂停、进入 `EVENT` 状态；事件面板关闭后，若无死亡/胜利/`trapped`，自动恢复剩余路径。AP 不足以走到目标点时，用 `_distance_for_cost` 反推可支付的最远距离，`_stop_movement(..., false)` 保留该 `visual_position`，不会把角色吸到格心。详见 D-09A/D-49/D-62。
- **事件引擎**：`EventManager` 负责触发、加权抽取、优先级队列、冷却、选项校验、2d6 检定、效果结算与一次性结局。事件数据在 `data/events/events.json`，UI 只渲染 `event_started / event_progress / event_finished` 与 `get_choices()`，不改规则。`random_events_enabled = false` 可关闭 POI/区域/wander 随机触发（终点守卫仍触发），供调试与自动化测试使用。详见 D-49。
- **区域触发**：`enter_region` 不是「每格都判定」，而是开局按地形连通分量生成区域 ID；玩家第一次跨入一个未访问区域的**边界格**时做 60% 判定，命中后从该地形的事件池抽取。POI 每个 `poi_id` 每局只在首次进入时触发一次。
- **事件密度、单局上限与分策略胜率（D-64）**：v1.12 与 v1.11 使用同一批固定种子，每策略 50 局。v1.12 复跑：只探索基线（不主动去终点，用来测事件密度）0W/1D/49T、平均 39.4 回合、24.5 事件/局；跨区域/POI/wander 份额与 v1.11 基本一致（v1.11 为 22.5% / 17.6% / 59.9%，中位数 26.5，41/50 落在 20～30）；49 次超时是「不冲终点」的策略结果，不是失败率。赶路 38W/11D/1T（76%，15.7 回合、16.0 事件/局）、谨慎 40W/10D（80%，21.0 回合、19.2 事件/局）、激进 9W/41D（18%，11.6 回合、11.9 事件/局）。三策略的封印拦截均为 0，检查点仪式都在进入终点前完成；守卫尝试分别为 163 / 173 / 48 次，通过 38 / 40 / 9 次（谨慎 v1.11 为 172 次）。单局随机事件达到 29 后不再触发新的 POI/区域/wander，终点守卫仍保留名额；未开始的队列事件跨回合保留。守卫触发份额不再当作事件池阈值；中立追击按同伴拆分，影为 29.4%/23.2% 属任务驱动，林鸮/薇拉均为 0%，仍按 ≤2% 严格核对。平衡 bot 固定选择知誓，仪式只增加金币；侦察 bot 不侦察，突袭 bot 不主动袭击同伴，因此 v1.12 的胜率、回合数与事件密度基本不变，谨慎多出的一次守卫尝试来自事件检定结果差异。侦察先机/洞察未改变 bot 的胜负层级，但玩家手动把侦察接到战斗前会直接获得 +2/+1 或 +3/+2。战斗蒙特卡洛：命中 35.7%、大成功 5.1%、失败 64.3%、大失败 22.6%、平均伤害 0.79，与 v1.11 完全一致，确认 `situational` 默认值 0 不影响普通攻击。
- **事件 UI**：`scenes/game/event_panel.tscn` 是覆盖在 HUD 上的独立面板；展示标题、触发类型/地形、事件文本、动态选项按钮、骰子明细与效果列表。交易/偷窃/献祭/古井会切换为对应的二级菜单，结算后显示「继续」，由玩家确认关闭。
- **状态与结局**：状态写入 `ActorState.statuses`，回合结束结算持续伤害、`trapped` 体力检定与持续时间。每个状态在 `statuses.json` 同时提供 `description`（完整效果，用于 tooltip/结算）与 `short`（状态条第 1 行短效果），避免长文本被裁切。事件结算、HUD 状态条与暂停页共用同一份状态数据。`lost`/`lost_severe` 在下一回合掷 AP 后扣 AP，不足按 D-10 转 HP。事件造成 HP ≤0 或通过终点守卫时，先把结局放进 `take_pending_outcome()`，由 `GameManager` 在 `event_finished` 后统一判负/判胜。详见 D-61。
- **AP 定点**：内部用 0.1 单位整数（deci-AP）避免浮点误差。移动成本 = 实际路径像素距离 × 基础系数 0.35 deci/px × 目标格地形系数 + 上坡高差 × 1.0 AP/级（绳索减半）；下坡不返还 AP。地形成本取决于目标格，爬升取决于 `elevation_at` 的起止采样点，所以靠近/远离边界、格内不同起点都会得到不同成本。单段路径成本封顶 3 AP，保证任何角色每回合至少能跨过一段；AI 寻路与可达性预览仍用格心到格心的近似 `move_cost_deci`，玩家实际移动则使用完整画线。详见 D-62/D-67。
- **自动存档与读档**：`SaveManager` 写单槽 `user://saves/auto.json`，只保存 `save_version / game_version / 时间戳 / meta / map / player / companion / events / rng / game`；地图只存生效配置与 `generated_seed`、`terrain_seed`，读档用 `MapGenerator.generate_exact()` 原样重建，不再走重试/兜底生成。`can_save_game()` 只在 PLAYING、序章已关、没有移动/暂停、没有活动事件和战斗时返回 true；序章关闭、移动停止、回合结束、侦察/休息/战斗结算以及返回主界面/退出都会尝试自动存档。读档先重建地图与 `current_vision`，再按存档中的 `seen/scouted/entered/poi_known` 逐格精确覆盖迷雾；RNG 的 64 位 state 以十进制字符串保存，恢复后事件流与 AI 流从存档点继续。胜利或死亡时清除自动存档。详见 D-63。
- **数据自检**：`DataManager.reload()` 会校验角色初始物品、隐藏任务归属、事件地形/属性、物品/状态/标记引用；错误会打印并显示在自检画面。地图配置由 `MapConfigLoader` 在启动和选择时校验。
